Field Operation Resequence

Compact field operation references safely

  • Renumbers all active and archived operations by creation date and ID.
  • Resets the global Field Operation sequence to the next available number.
  • Restricted to Head Office and Admin roles.
  • Warns before changing references used by printed documents.

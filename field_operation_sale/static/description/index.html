Field Operation Sale

Field Operation Sale integration

  • Servis → Satış: tamamlanmış (status = 'done') saha işinden tek butonla satış siparişi üretimi (wizard)
  • Satış → Servis: sale.order üzerindeki Service butonu ile her ürün satırına karşılık ayrı field.operation kaydı üretimi
  • Fatura bağı: satıştan doğan faturaya servis referansını taşır, fatura formuna "Services" akıllı butonu ekler
  • Ürün eşlemesi: ürün kartında service_type_id ile ürün → servis tipi bağlantısı
  • Ayarlar: grup bazlı özellik anahtarı + varsayılan satış ürünü parametresi

Field Operation Attendance Report

Monthly field operation attendance report for employees

  • Veri kaynağı: status = 'done' olan, start_date'i seçilen aya düşen field.operation
  • Sihirbaz (field.operation.attendance.wizard): ay, yıl, çalışan seçimi (boş = tüm aktif
  • PDF: Landscape A4 raporu (action_report_attendance → report.field_operation_attendance.report_attendance);
  • Excel/CSV: action_export_xlsx — xlsxwriter varsa XLSX üretir, yoksa (veya hata olursa)
  • Menü ve buton: Reporting → Monthly Work Schedule; ayrıca field.operation kaydı

Field Operation Contract Repeat Wizard

Manual recurring operations wizard for Field Operation Contracts

  • Sıklıklar: günlük, haftalık, aylık, yıllık; haftalık/aylık için ek seçenekler
  • Bitiş koşulu: belirli adet (count) veya belirli tarih (until)
  • Güvenlik sınırı: tek çalıştırmada max_recurring_operations (varsayılan 500) kayıt
  • Üretilen kayıtlar doğrudan status = planned yazılır
